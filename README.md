\# Sistem AES + Genetic Algorithm



\## Deskripsi

Sistem enkripsi AES yang dioptimasi menggunakan Genetic Algorithm untuk menghasilkan kunci yang lebih optimal dan aman.



\## Fitur

\- AES Baseline

\- AES + Genetic Algorithm

\- Pengujian NIST (Frequency Test \& Runs Test)

\- Analisis Entropy



\## Tujuan

Meningkatkan kualitas kunci enkripsi AES menggunakan pendekatan algoritma genetika.



\## Teknologi

\- Python / Flask (Backend)

\- HTML, CSS, JavaScript (Frontend)



\## Cara Menjalankan

1\. Jalankan server

2\. Buka browser

3\. Masukkan plaintext

4\. Pilih metode (AES / AES+GA)

5\. Lihat hasil enkripsi dan pengujian
